## 🌟 Key Features

- **Modern Rounded UI & Design System**: Sleek glassmorphism cards, rounded buttons, and polished aesthetics across all devices.
- **Multi-Theme Support**: Instant switching between **Obsidian Black**, **Cyber Electric Blue**, **Neon Cyber Pink**, and **Clean Minimal Light** with persistent `localStorage` preference.
- **Interactive Particle Network Canvas**: Dynamic neural connection graph in the Hero section reacting to cursor movement and theme palettes.
- **Role Typewriter**: Animated headline rotating through core technical titles.
- **Interactive Code & Terminal Inspector**: Live code viewer with Python algorithms from real projects and an interactive shell (`whoami`, `skills`, `projects`, `experience`, `education`, `contact`).
- **Live Skill Search**: Real-time filtering and searching of technical competencies, frameworks, and programming tools.
- **Dedicated Education Section**: Academic background for **NBKRIST** (B.Tech AI & Data Science) and **SR Junior College** with key coursework tags.
- **Prominent "Connect via Mail"**: Direct 1-click email actions (`mailto:duvvuruharshanthreddy@gmail.com`) and quick-select topic chips.
- **100% Authentic Resume Data**: Complete academic background, internships at *Supraja Technologies* and *Pentagon Space*, *Narayana 24H Hackathon* achievement, and direct contact details.
- **Interactive CV Modal**: Full printable and downloadable resume viewer.
- **Framer Motion Animations**: Viewport scroll reveals, stagger animations, and glowing badges.

## 🚀 Getting Started

### 1. Clone the repository:
```bash
git clone https://github.com/likhith3035/harsha-s-portfolio-.git
cd harsha-s-portfolio-
```

### 2. Install dependencies:
```bash
npm install
```

### 3. Run development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### 4. Build for production:
```bash
npm run build
npm start
```
